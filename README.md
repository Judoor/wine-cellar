# 🍷 Wine Cellar

A self-hosted wine cellar manager: track your bottles, place them in a visual 2D cellar,
follow drinking windows, write tasting notes. Multi-user, English & French.

## Run with Docker Compose (Dockge, Portainer, TrueNAS…)

Use [`docker-compose.yml`](docker-compose.yml) — paste it into Dockge/Portainer, or:

```bash
docker compose up -d
```

Open `http://<server-ip>:3000`. **The first account created becomes the administrator.**
The administrator can then close registrations from the *Administration* page.
French step-by-step guide: [docs/installation-fr.md](docs/installation-fr.md).

### Environment variables

| Variable | Default | Description |
|---|---|---|
| `PUID` / `PGID` | `1000` | Owner of the data folder; the container fixes ownership at startup. TrueNAS: `568`. |
| `TZ` | – | Time zone, e.g. `Europe/Paris`. |
| `ALLOW_REGISTRATION` | `true` | `false` forbids new sign-ups (the very first account can always be created). |
| `SECURE_COOKIES` | `false` | Set to `true` when the app is served over HTTPS (reverse proxy, Tailscale). |
| `DISABLE_EXTERNAL_LOOKUPS` | `false` | `true` disables the barcode lookup on Open Food Facts. |
| `DATA_DIR` | `/data` | Where the SQLite database and uploads are stored. |

### Install on your phone (PWA)

Browsers only allow installing the app (home-screen icon, full screen) over **HTTPS**. Put it behind a reverse proxy
or use `tailscale serve --bg 3000`, set `SECURE_COOKIES=true`, then use *Install app* (Android) / *Add to Home Screen* (iOS).

### Backup

Everything lives in the `data` folder (`winecellar.db` + `uploads/`). Stop the container and copy the folder.

## Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Database schema changes: edit `src/lib/db/schema.ts`, then run
`npx drizzle-kit generate` — migrations are applied automatically at startup.

### Wine catalog

The offline catalog used for quick fill (`catalog/catalog.db.gz`) is generated by
`node scripts/catalog/build.mjs`, which downloads its sources into `.cache/catalog`.

## Data sources

- **X-Wines** — 100,646 wines, CC0. R. X. de Azambuja, A. J. Morais, V. Filipe, *X-Wines: A Wine Dataset for Recommender Systems and Machine Learning*, Big Data Cogn. Comput. 2023, 7(1), 20. https://github.com/rogerioxavier/X-Wines
- **INAO** — French AOP/IGP appellations, via [data.gouv.fr](https://www.data.gouv.fr/datasets/aires-et-produits-aoc-aop-et-igp/), Licence Ouverte / Etalab.
- **Open Food Facts** — barcode lookup (online, optional, can be disabled by the administrator), ODbL. https://world.openfoodfacts.org

Drinking-window estimates are indicative rules of thumb, not expert ratings.

### Adding a language

1. Copy `src/i18n/messages/en.ts` to `src/i18n/messages/<code>.ts` and translate it.
2. Register it in `src/i18n/config.ts`.
